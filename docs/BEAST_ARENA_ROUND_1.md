## 维护规则

1. 先用“禁止使用道具：斗兽奇弈”确定一局开始，用最后一条“战斗结束”确定结束。
2. 如果日志文件包含多局，按时间或行号切分后再比较，不能直接对整份文件做差集。
3. 以可选中的非 `9020` 实体作为 Boss 本体；`9020` 通常是同名的不可选中机制实体。
4. 同名技能可能有多个 Action ID，全部保留，不能只保留 Boss 本体的起始读条 ID。
5. 新 Boss 按场次建立分支，例如“第二场分支 C”，不要覆盖已有随机分支。
6. 只记录日志实际出现的数据；名称为空时写“未记录”。
