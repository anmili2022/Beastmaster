# 发布说明

## 开发中

### 插件图标

- 将插件图标从 `1280×1280` 缩放为 `150×150`，并更新 `IconUrl` 缓存版本，修复 Dalamud 插件列表显示问号的问题

### 推荐装备

- 修正 50 级 BIS 方案的主手和副手为兽主手斧、兽主青铜重盾
- 新增“推荐装备”栏目
- 记录驯兽师 50 级开荒装
- 新增 50 级 BIS 装备方案，可在页面下拉框切换
- 装备名称支持点击打开对应的灰机 Wiki 物品详情页
- 推荐装备新增背包/兵装库持有状态显示
- 推荐装备持有检测改为固定 ItemId；已装备物品单独显示“已装备”

### 量谱与魔兽资料

- 自动输出“当前量谱”新增生息（白）与死灭（黑/紫）状态检测
- 新增驯兽师量谱只读读取：技力、兽力、当前兽笛、御兽之心、兽灵之心
- 技力和兽力显示上限统一为 250，悬浮窗简写为「技力 / 兽力」
- 新增当前召唤兽识别，显示图鉴名称和猛/坚/魔/翔属性
- 魔兽图鉴新增属性列和大招/释放技能列
- 新增 `docs/BST_GAUGE.md`，记录量谱偏移、属性映射和技能资料

### 自动输出

- 基础 `1→2→3` 连击统一按 `6 yalms` 检查玩家到目标距离，超距时不发送技能请求，修复远距离持续转向目标的问题
- 技能序列、规则模式和距离等待默语统一增加 `HH:mm:ss` 时间戳，格式为 `[驯兽师助手 15:45:15]`
- 自动输出新增“自动输出诊断”开关；普通 ACR 已选技能无法释放时，按技能和失败类型节流输出距离、状态码、资源快照、前置状态或请求失败原因；自动输出页面移除量谱原始数据和量谱说明
- 修复距离等待默语开关无法保存的问题；选中玩家自身时按无有效敌对目标处理，不再尝试释放技能
- 自动释放和技能序列中的释放改用当前召唤兽到目标的距离判断；射程读取召唤兽图鉴实际释放技能的 `Range/EffectRange`，未进入射程时等待而不提前请求
- 技能序列按实际调整后 ActionId 检查技能要求等级；角色等级不足时直接跳过倒计时或战斗步骤并继续执行
- 技能序列战斗步骤超时时输出步骤名称、基础/调整后 ActionId、`GetActionStatus` 或 `UseAction` 失败结果、目标和重试次数，便于定位技能未释放原因
- 新增独立“规则模式”栏目：支持规则集、TerritoryType 区域限制、五类 BUFF/读条条件、规则排序、剪贴板导入导出和分级默语诊断；规则仅在战斗中运行，优先级为技能序列 > 规则模式 > 普通 ACR
- 持续吸引和持续挑衅改为规则模式内置规则，移除自动输出悬浮窗中的斗兽塔技能设置；规则模式默认开启，两条内置规则默认关闭

- 修正技能序列将借用后的本能技能固定判断为百兽肤的问题；现在按导入序列动态确认百兽肤、百虫肤等技能，内置虫队模板使用百兽肤
- 修正捕获血量阈值边界，目标血量等于阈值时也会使用捕获，`100%` 阈值包含满血目标
- 新增“主动攻击”开关和悬浮窗灰/绿“主动”标签；关闭时未进战不攻击、不捕获，也不使用斗兽塔技能
- 主动攻击关闭时仍允许自动兽笛等无目标准备动作；后续技能序列明确不受主动攻击开关限制
- 最后一击改为 1/2/3 笛独立开关和独立宝宝血量阈值；悬浮窗仅保留紧凑开关
- 新增“最后一击 · 等待释放”，开启后仅在当前魔兽已使用释放且释放技能不可用时使用最后一击
- 新增内置“虫队模版序列”，按团队倒计时执行三号笛、借用、一号笛、百兽肤和盾牌冲击，并在进战后接续固定输出
- 新增默认关闭的“测试序列”：T-3 一号兽笛、T-0 盾牌冲击，进战后使用碎击斩
- 技能序列栏目新增默语提示开关，输出序列启动、技能请求、完成和中止状态，并对重复消息节流
- 新增命令控制：`/驯兽师 输出`切换自动/暂停状态，`暂停`、`恢复`、`关闭`提供显式控制；英文命令支持对应的 `output`、`pause`、`resume`、`off`
- 基础技能、捕获和捕获状态改为固定 RowId，不再通过中文名称解析，兼容国际服英文客户端
- 悬浮窗不可执行原因拆分显示，区分技能节流、切图、骑乘、剧情占用、死亡和读条
- 新增捕获三态标签：灰色“捕获”表示关闭，绿色“捕获”表示尝试捕获，红色“捕获”表示强制捕获
- 修正强制捕获规则：无视目标已有捕获 Buff，但仍受捕获血量阈值限制
- 悬浮窗标题栏点击“捕获”标签可按关闭→尝试捕获→强制捕获→关闭循环切换
- 自动输出栏目新增“强制捕获”开关；强制捕获时无视目标血量和捕获 Buff
- 新增斗兽塔技能折叠栏；区域 1339~1343 内支持持续吸引（宝宝抗）和持续挑衅（自己抗），默认关闭
- 修正黄豆与蓝豆协作时序：第一段后等待人物自身对应的一式属性 Buff，再释放第二段；等待窗口调整为 7 秒
- 明确魔兽“释放”技能与黄豆/蓝豆量谱独立，不再用黄豆变化或宝宝读条判断释放完成
- 新增最后一击及宝宝血量阈值，宝宝低血量时对当前敌对目标使用最后一击；说明改为控件悬停提示，避免撑高悬浮窗
- 新增自动兽笛：无魔兽时按兽笛 1→2→3 使用首个可用技能，并等待 1 秒确认召唤，避免连续误用下一支兽笛
- 高级技能选项改为折叠栏，避免悬浮窗过高
- 移除重复的“启用高级技能”总开关，各高级技能改由自身开关独立控制
- “尝试捕获”下方新增基础技能（1→2→3）独立开关
- 高级技能新增互斥的“万象流转（物理）”和“万象流转（魔法）”选项，按御兽之心、鼓劲及黑白状态自动选择四种终结技能
- 万象流转（物理）和万象流转（魔法）增加对应悬停提示
- 根据实测修正三式黑白映射：白使用利鹰坚爪/灾祸天翔，黑使用狂猛怒火/升魔暴落
- 自动输出新增独立暂停状态；主栏目和悬浮窗标题栏可同步暂停或恢复，不再关闭自动输出总开关
- 当前职业不是驯兽师时自动隐藏驯兽ACR悬浮窗
- 暂存兽笛循环连招设计：一号兽笛→释放→最后一击→二号兽笛→释放→最后一击→三号兽笛→释放；当前暂时禁用入口和自动执行逻辑，待后续验证后恢复
