# 发布说明

## 开发中

### 推荐装备

- 新增“推荐装备”栏目
- 记录驯兽师 50 级开荒装
- 新增 50 级 BIS 装备方案，可在页面下拉框切换
- 装备名称支持点击打开对应的灰机 Wiki 物品详情页
- 推荐装备新增背包/兵装库持有状态显示
- 推荐装备持有检测改为固定 ItemId；已装备物品单独显示“已装备”

### 量谱与魔兽资料

- 自动输出“当前量谱”新增生息（白）与死灭（黑/紫）状态检测
- 新增驯兽师量谱只读读取：技力、兽力、当前兽笛、御兽之心、兽灵之心
- 技力和兽力显示上限统一为 250，悬浮窗简写为「技力 / 兽力」
- 新增当前召唤兽识别，显示图鉴名称和猛/坚/魔/翔属性
- 魔兽图鉴新增属性列和大招/释放技能列
- 新增 `docs/BST_GAUGE.md`，记录量谱偏移、属性映射和技能资料

### 自动输出

- 新增斗兽塔技能折叠栏；区域 1339~1343 内支持持续吸引（宝宝抗）和持续挑衅（自己抗），默认关闭
- 修正黄豆与蓝豆协作时序：第一段后等待人物自身对应的一式属性 Buff，再释放第二段；等待窗口调整为 7 秒
- 明确魔兽“释放”技能与黄豆/蓝豆量谱独立，不再用黄豆变化或宝宝读条判断释放完成
- 新增自动最后一击及宝宝血量阈值，宝宝低血量时对当前敌对目标使用最后一击；说明改为控件悬停提示，避免撑高悬浮窗
- 新增自动兽笛：无魔兽时按兽笛 1→2→3 使用首个可用技能，并等待 1 秒确认召唤，避免连续误用下一支兽笛
- 高级技能选项改为折叠栏，避免悬浮窗过高
- 移除重复的“启用高级技能”总开关，各高级技能改由自身开关独立控制
- “尝试捕获”下方新增基础技能（1→2→3）独立开关
- 高级技能新增互斥的“三式（物理）”和“三式（魔法）”选项，按御兽之心、鼓劲及黑白状态自动选择四种终结技能
- 三式（物理）和三式（魔法）增加“万象流转·物理/魔法”悬停提示
- 根据实测修正三式黑白映射：白使用利鹰坚爪/灾祸天翔，黑使用狂猛怒火/升魔暴落
- 自动输出新增独立暂停状态；主栏目和悬浮窗标题栏可同步暂停或恢复，不再关闭自动输出总开关
- 当前职业不是驯兽师时自动隐藏驯兽ACR悬浮窗
- 暂存兽笛循环连招设计：一号兽笛→释放→最后一击→二号兽笛→释放→最后一击→三号兽笛→释放；当前暂时禁用入口和自动执行逻辑，待后续验证后恢复

### 任务导航

- 修复任务链“导航到开始 NPC”固定使用步行的问题，统一使用飞行导航逻辑
- 新增 `docs/BST_ACR_DESIGN.md`，记录 ACR 状态、优先级、开关和安全边界
- 捕获状态判断增加来源校验，仅自身施加的捕获状态会阻止重复捕获
- 新增捕获血量阈值设置，默认目标血量低于 80% 时释放捕获
- 自动输出页面和悬浮窗均可直接修改捕获阈值
- 自动输出栏目新增「详细模式」开关，默认关闭时隐藏悬浮窗的原因和捕获状态详情
- DEBUG 量谱原始数据与正式量谱区统一使用 `CurrentGauge` 数据起点
- 配置版本升级为 8，并迁移捕获血量阈值
- 自动输出悬浮窗标题统一为「驯兽ACR」
- 悬浮窗新增高级技能总开关、御兽协作（黄豆）和兽灵协作（蓝豆）互斥开关
- 新增“释放”独立开关，可临时关闭召唤兽释放技能
- 新增统一技能可用性结果和失败原因显示
- 自动输出悬浮窗显示资源状态和高级技能判断状态
- 新增手动大招按钮；协作模式包含自动大招请求并使用资源和 ActionManager 判断
- 高级技能新增当前魔兽“释放”技能冷却完成自动使用
- 修正魔兽“释放”技能使用运行时调整后的 `ActionType.Action`，避免被判断为当前职业不可用
- 修正释放技能冷却/状态码非零时不再重复请求，基础 1-2-3 连击继续执行
- 图鉴属性和技能映射复用统一数据模型

### DEBUG

- 关键词查询新增区域 TerritoryType，可按 `1339`、`1340` 等 ID 精确读取区域名、Map.RowId 和关联副本
- 新增「读取魔兽属性映射」按钮
- 输出 50 个图鉴魔兽的 DataId、大招/释放 ActionId、技能名称、IconId 和属性
- 新增当前目标状态和当前连击状态 DEBUG 诊断按钮
- 新增推荐装备 ItemId DEBUG 查询按钮，便于改为 ID 持有检测
- 新增统一魔兽技能资料模型 `BeastmasterSkillProfile`
