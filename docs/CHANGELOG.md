# 发布说明

## 开发中

- 斗兽攻略高段第二盘新增 14 组怪物与一句话机制资料，作者沿用“其他母肥角色@拂晓之间”；不录入坐标、节点和 DataID
- 协作二段改为以人物现有一式 Buff 为最终资格：有 pending 时优先预期 Buff，无 pending 时按固定属性优先级恢复二段；已有 Buff 时不重复一段并禁止最后一击
- 移除普通 ACR 的独立自动大招：御兽/兽灵协作都关闭时不再自动消耗双 100，资源保持积攒；手动大招和技能序列不受影响
- 修复协作二段已获得对应 Buff 后可能被每 GCD 两个能力技上限挡住的问题；待续二段在安全窗口优先尝试，完成/超时/重置前禁止最后一击，其他能力技仍可使用
- 自动输出诊断补充协作一段来源、待续二段 Action/Buff、GCD 剩余时间、能力技计数、保护阻挡、超时及重置原因，便于定位大招后未释放二段的问题

- 技能序列倒计时时间输入框移除 `- / +` 步进按钮并扩大可编辑区域，改善高 UI 缩放下无法输入的问题；序列可选技能新增挑衅 `46750` 和吸引注意 `46751`
- 修复倒计时编辑器将界面中的 `T-4.0` 保存为正数 `4.0`，导致视觉顺序正确但序列校验失败的问题；输入值现自动转换为内部负数
- 配置 Version 46 自动将历史序列中误保存的正数倒计时时间转换为对应负数，无需逐项重新编辑
- 重排普通 ACR 技能优先级：GCD 转好时仅执行万象流转和基础连击；协作二段、协作一段改为 GCD 转圈且剩余时间大于 0.7 秒时的最高优先级 OGCD，等待 Buff 时不再冻结基础 GCD
- 技能序列改为绕过释放后/最后一击后的两种全局 5 秒保护，并且序列中的释放与最后一击不写入保护计时，确保严格按用户编排步骤执行
- 新增 `/驯兽师助手` 命令别名，与 `/驯兽师` 支持相同的输出、暂停、恢复、关闭和自定义倒计时子命令
- 自定义倒计时运行中重复执行启动命令时不再重置并重复刷启动消息，仅提示当前剩余秒数
- 修复技能序列战斗步骤未给碎咬斧等目标技能传递当前目标，导致 `GetActionStatus=0` 但 `UseAction=false` 并在步骤 4 超时的问题
- 修正兽灵协作（蓝豆）第一段属性选择：从当前魔兽的下一属性改为上一属性，等待该属性对应的一式 Buff 后再使用大招
- 修复基础连击 `GetActionStatus` 非零时被误判为 GCD 转圈的问题；能力技现在仅在真实 recast 活动期间穿插，避免 GCD 已转好后释放大招并延后下一发 GCD
- 自动大招 GCD 安全窗口提高到 `1.7s`：按实测约 `1.6s` 的动作锁预留缓冲，避免大招将下一次 GCD 延后约 850ms
- 斗兽攻略第二盘新增 7 组怪物机制与“偷偷说”资料，作者沿用“其他母肥角色@拂晓之间”；不录入坐标和 DataID

- 规则奇弈道具异步结果改为每帧处理，不再等待规则再次命中或手动使用道具后才显示超时原因
- 修复奇弈道具切换到 `ExecuteSlotById` 后未传递软目标，导致各种牙和吸血鬼之牙无法对敌对目标使用的问题
