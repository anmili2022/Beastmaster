# 发布说明

## 0.1.5.0

### 图鉴导航与数据修正

- 修正 16 至 42 号野外图鉴的客户端 `TerritoryType` 映射，避免传送到错误地图或找不到以太水晶
- 为 25 号「精金龟」补充客户端位置：`TerritoryType=141`、`Map.RowId=21`、世界坐标 `-101.513, 5.07, 238.304`
- 为 40 号「幽灵」补充等级 7、地图标识和世界坐标 `-58.393, 27.135, -119.884`
- 为副本图鉴条目保存 `ContentFinderCondition.RowId`，打开任务搜索器时优先使用副本 ID
- 增加 DEBUG「读取图鉴副本 ID」查询按钮
- vnavmesh 未就绪时改为低频等待，准备完成后自动继续导航；图鉴导航会重新判断飞行和坐骑状态
- 当前地图排序改为按地图名称匹配，当前地图优先置顶

## 0.1.0.0

首个公开发布版本。

### 驯兽师任务链

- 13 项线性任务（71026→71045），支持客户端状态实时读取
- 前置条件绿/红文字提示
- 开始 NPC 导航（Lifestream 跨地图传送 + vnavmesh 寻路）
- 任务目标坐标核对：71026 Sequence 1（黑衣森林中央林区）

### 魔兽图鉴

- 50 条图鉴数据，区分野外、副本、初始自带、未知位置
- 按角色独立保存完成状态
- "按地图排序"（当前地图优先）
- 停止导航按钮
- 飞行导航自动上坐骑，8 秒超时降级步行

### 快捷指令

- "魔兽图鉴"按钮：通过 UIModule 执行 `/魔兽图鉴`

### DEBUG 页面

- 按名称搜索任务、物品、NPC、怪物、副本、职业
- 当前所有任务状态采集
- 当前角色和位置信息

### 发布流程

- GitHub Actions 自动构建 + Release
- 本地 release.ps1 版本发布脚本
- Dalamud 自定义插件仓库（repo.json）
- 插件图标（icon.png）
