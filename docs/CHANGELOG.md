# 发布说明

## 0.1.7.0

### 自动捕获

- 设置页新增「自动捕获」开关，默认关闭
- 仅对当前手动选择的目标执行，不自动搜索或切换目标
- 副本内同样允许运行
- 目标没有「待捕获」状态时优先释放「捕获」
- 使用 1→2→3 连击：碎击斩、碎咬斧、裂盾劈
- 悬浮窗显示当前状态和下一个技能
- 悬浮窗提供「尝试捕获」开关，关闭时只执行 1→2→3 连击
- 开启时显示「自动捕获中...」，关闭时显示「自动攻击中...」
- 自动捕获使用客户端确认的 Action/Status 数据：44879、44883、44885、44880、4626

### DEBUG

- 新增「读取自动捕获 ID」按钮，输出技能、捕获状态和当前目标状态

## 0.1.0.0

首个公开发布版本。

### 驯兽师任务链

- 13 项线性任务（71026→71045），支持客户端状态实时读取
- 前置条件绿/红文字提示
- 开始 NPC 导航（Lifestream 跨地图传送 + vnavmesh 寻路）
- 任务目标坐标核对：71026 Sequence 1（黑衣森林中央林区）

### 魔兽图鉴

- 50 条图鉴数据，区分野外、副本、初始自带、未知位置
- 按角色独立保存完成状态
- "按地图排序"（当前地图优先）
- 停止导航按钮
- 飞行导航自动上坐骑，8 秒超时降级步行

### 快捷指令

- "魔兽图鉴"按钮：通过 UIModule 执行 `/魔兽图鉴`

### DEBUG 页面

- 按名称搜索任务、物品、NPC、怪物、副本、职业
- 当前所有任务状态采集
- 当前角色和位置信息

### 发布流程

- GitHub Actions 自动构建 + Release
- 本地 release.ps1 版本发布脚本
- Dalamud 自定义插件仓库（repo.json）
- 插件图标（icon.png）
