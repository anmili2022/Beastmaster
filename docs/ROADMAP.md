# 驯兽师助手开发路线

## 项目位置

- 项目目录：`E:\git\Beastmaster`

## 当前状态

插件已进入公开发布阶段，基础功能全部完成。当前准备发布版本 `0.1.27.0`，标题栏动态显示版本号。

### 已完成功能

**任务系统**

- 13 项驯兽师线性任务链（71026→71027→...→71037→71045）
- 客户端实时任务状态读取，每 2 秒自动刷新
- 前置条件绿/红文字提示（已完成/未完成）
- 开始 NPC 导航：Lifestream 跨地图传送 + vnavmesh 路径寻找
- 任务目标坐标已核对：71026 Sequence 1（TerritoryType=148，Map=4，X=-318.654, Y=60.947, Z=-129.382）

**魔兽图鉴**

- 50 条图鉴数据，与灰机wiki对齐（名称、等级、获取方式）
- 每条显示：编号、名称、属性、技能、等级、所属地图、获取方式、完成状态
- 属性按猛/坚/魔/翔彩色显示
- 技能列显示当前魔兽大招和释放技能
- 鼠标悬停技能列显示 ActionId、技能等级、射程和范围
- 8 列表格布局，支持点击导航按钮直达
- 飞行导航自动上坐骑，8 秒超时或战斗中降级为步行
- 停止导航按钮
- "按地图排序"黄色复选框（当前地图优先）
- 当前地图排序使用 `TerritoryType/Map.RowId` 判断，避免依赖本地化地图名称
- "按等级排序"复选框，区间等级按最低等级排序
- "隐藏已捕获魔兽"复选框
- **WIKI** 链接按钮，跳转 `ff14.huijiwiki.com/wiki/魔兽图鉴`
- **等级** 列，数据来源于wiki

**推荐装备**

- 新增推荐装备栏目
- 记录驯兽师 50 级开荒装：武器、盾牌、防具、饰品和职业证
- 记录第二套 50 级 BIS，可在推荐装备页切换方案
- 装备名称可点击访问对应的灰机 Wiki 物品详情页
- 推荐装备显示背包和对应兵装库中的持有状态及数量
- 新增独立“推荐组合”栏目，静态展示虫队、水队和水队速刷变体，并提供 Bilibili 参考视频链接
- 推荐装备持有状态改为固定 ItemId 检测，避免装备同名或名称变化导致误判

**快捷指令**

- "魔兽图鉴"按钮：通过 UIModule 执行 `/魔兽图鉴`（不使用 ICommandManager）
- 驯兽师魔兽体型按钮：`/beastpetsize all small`、`medium`、`large`
- `/驯兽师 输出`切换自动输出和暂停状态，`暂停`、`恢复`、`关闭`提供显式控制；英文命令支持 `output`、`pause`、`resume`、`off`
- `/驯兽师 倒计时 [秒数]`启动自定义倒计时（默认 10 秒），触发技能序列；`取消倒计时`取消进行中的自定义倒计时

**自动记录**

- `BeastmasterCatalogChatTracker`：监听聊天消息，匹配 `成功结识了……种的魔兽！` 自动标记完成
- `羊羔` 别名映射到 `迷途羊羔`
- 设置页"捕获消息自动记录"开关（默认开启）

**自动捕获**

- 设置页提供自动捕获开关，默认关闭
- 只对当前手动选择的目标运行，不自动选择或切换目标
- 支持副本内运行
- 目标无「待捕获」状态时优先释放捕获
- 捕获后按驯兽师连击释放碎击斩、碎咬斧、裂盾劈
- 悬浮窗显示「自动捕获中...」或「自动攻击中...」以及下一个技能
- 悬浮窗「尝试捕获」关闭后只执行 1→2→3 连击
- 左侧独立「自动输出」栏目管理自动输出总开关
- 自动输出悬浮窗标题为「驯兽ACR」
- 当前职业不是驯兽师时自动隐藏悬浮窗，切回驯兽师后自动恢复
- 任务开始 NPC 导航复用飞行导航逻辑，支持自动上坐骑和步行回退
- 悬浮窗显示当前魔兽、属性、技力、兽力、御兽之心、兽灵之心和决策原因
- 悬浮窗可直接切换御兽协作（黄豆）和兽灵协作（蓝豆）
- 悬浮窗和自动输出栏目可切换互斥的万象流转（物理）与万象流转（魔法）
- 悬浮窗标题栏和自动输出栏目共享独立暂停状态，不关闭自动输出总开关
- 悬浮窗标题栏提供捕获三态标签：灰色关闭、绿色尝试捕获、红色强制捕获；强制捕获无视目标捕获 Buff，但仍受血量阈值限制
- 自动输出提供“主动攻击”开关和悬浮窗灰/绿标签；关闭时未进战不执行普通 ACR 攻击或捕获，技能序列不受该开关限制，规则模式仅在战斗中运行
- 悬浮窗“尝试捕获”下方提供基础技能（1→2→3）独立开关
- 高级技能使用折叠栏，支持无魔兽时按 1→2→3 优先级自动使用兽笛
- 高级技能支持按宝宝血量阈值使用最后一击
- 最后一击按 1/2/3 笛提供独立开关和阈值，并支持等待当前魔兽使用释放后再执行
- 最后一击血量判断使用小于等于阈值，`100%` 阈值包含满血宝宝；等待释放开启时，释放距离不足也继续等待
- 规则模式内置斗兽塔规则集：区域 1339~1343 内可独立开启持续吸引（宝宝抗）和持续挑衅（自己抗）
- 规则模式支持目标 DATAID 条件及奇弈道具执行；默认规则集包含启用的“最终爆发-1层”（目标 DataID 19344，使用各种牙）
- 悬浮窗可直接切换“释放”开关
- 悬浮窗可直接调整捕获血量阈值，默认 80%
- 自动输出栏目提供「详细模式」开关，默认关闭
- 自动输出栏目提供「自动输出诊断」总开关；插件内部记录全部普通 ACR 状态边沿、成功请求和失败原因，保留最近 10 场内存日志并支持选择、复制和清空
- 自动输出栏目提供默认关闭的悬浮窗三列模式，按四行三列排列高级技能按钮
- 捕获状态按 Status.SourceId 区分自身施加和他人施加的状态
- 捕获请求增加等待结果和目标切换重置，避免短时间重复请求
- 基础技能、捕获和捕获状态使用固定 RowId，兼容国际服英文客户端
- 基础 1→2→3 连击按 6 yalms 检查玩家到目标距离，超距时不发送技能请求，避免持续转向目标
- 角色不可执行原因拆分显示，区分技能节流、切图、骑乘、剧情占用、死亡和读条
- 悬浮窗右键打开设置页面
- 工具列表新增“前往斗兽塔”，导航目标为 TerritoryType 148、Map.RowId 4、黑衣森林中央林区坐标 `X=24.238, Y=-6.003, Z=65.809`

**量谱与高级技能**

- 从 `JobGaugeManager.Instance()->CurrentGauge` 只读读取驯兽师量谱
- 技力：`CurrentGauge +0x10`，上限 250
- 兽力：`CurrentGauge +0x11`，上限 250
- 当前兽笛：`CurrentGauge +0x13`
- 御兽之心/兽灵之心：`CurrentGauge +0x18` 位字段
- 每 100 毫秒采样一次，UI 使用缓存，避免每帧访问游戏内存
- 自动输出增加统一 Action 可用性结果和失败原因
- 高级技能支持手动大招；御兽协作（黄豆）和兽灵协作（蓝豆）互斥，协作流程自动包含大招
- 黄豆和蓝豆协作第二段均等待人物自身对应的一式属性 Buff：翔 4595、猛 4596、坚 4597、魔 4598，等待窗口为 7 秒
- “释放”开启后，当前魔兽释放技能通过运行时调整 ID 和 Action 状态判断，冷却中回退基础技能
- 魔兽释放使用宝宝到目标碰撞箱边缘的距离；`Range/EffectRange` 均为 `0` 时跳过显式距离门禁并依赖 `GetActionStatus`
- 鼓劲和声援为独立默认关闭开关；对应御兽/兽灵之心为 0 时正常判断，大于 0 时要求开启任一万象流转模式
- 安全盾牌作为普通 ACR 技能，优先级位于协作一段之后、捕获之前；玩家到目标不超过 3 yalms 且盾牌冲击可用时自动使用，并纳入自动输出诊断
- 安全盾牌成功请求后增加独立 2 秒冷却，防止动作状态短暂恢复时连续发送；关闭、暂停或复活时重置
- 新增默认关闭的低血量自动恢复药，默认阈值 30%，仅在斗兽塔战斗中按3级→2级→1级优先使用奇弈恢复药；60%阈值实测已成功使用3级药
- 奇弈恢复药通过 Agent 497 显示槽位映射、InstanceContentDirector 库存校验和 `RaptureHotbarModule.ExecuteSlot` 执行，不使用普通背包 Item Action 或未知 FireCallback
- 规则奇弈道具固定分为恢复药和各种牙；恢复药按 3级→2级→1级，已确认牙 ID 为 128/129/131/133，并按可用状态自动选择
- 规则诊断完整级别输出成功动作；同一规则相同失败原因只输出一次，失败原因变化时才重新输出
- 各种牙自动投掷、奇弈道具 DEBUG 过滤、BOSS BUFF 规则和规则恢复药路径均已完成游戏内验证
- 三式仅在自身存在生息/死灭且御兽之心达到 3 层时使用鼓劲，再按客户端实测黑白映射选择物理或魔法终结技能
- 自动兽笛请求成功后等待 1 秒确认召唤，确认前不尝试下一支兽笛
- 兽笛循环连招设计已记录但当前暂时禁用：一号兽笛→释放→最后一击→二号兽笛→释放→最后一击→三号兽笛→释放；完成后等待一号兽笛冷却
