# 驯兽师量谱资料

本文档根据驯兽师职业量谱说明截图及 `XSZYYS_PR` 反编译结果整理。

## 量谱字段

当前插件从 `JobGaugeManager.Instance()->CurrentGauge` 读取 48 字节，并使用以下字段：

| 偏移 | 当前显示名称 | 说明 |
| --- | --- | --- |
| `+0x10` | 技力 | 反编译代码中的旧字段名为 `Tp`，当前上限为 250 |
| `+0x11` | 兽力 | 反编译代码中的旧字段名为 `BeastPower`，当前上限为 250 |
| `+0x13` | 当前兽笛 | `1~3` 分别表示一号、二号、三号兽笛，其他值表示未召唤 |
| `+0x18` 高位 | 御兽之心 | 原始值右移 2 位：`raw >> 2` |
| `+0x18` 低位 | 兽灵之心 | 原始值低 2 位：`raw & 3` |

“当前量谱”还会读取玩家自身状态列表，显示黑白状态：

- `4599`：生息（白）
- `4600`：死灭（参考实现显示为紫，界面兼容显示为黑/紫）

这两项来自玩家状态，不是 `CurrentGauge` 的字节字段。

## 释放逻辑记录

- 大招需要消耗魔兽技力，截图记录的要求是魔兽技力至少达到 `100`。
- 反编译代码中的连招检查也要求魔兽技力达到 `100`。
- 反编译代码还会检查技能量是否达到 `100`，并在爆发技能中检查技能量是否达到 `250`。
- 大招与对应属性斧的释放顺序取决于属性链，并非固定只先释放大招或只先释放斧技。
- 属性循环按 `翔 → 猛 → 坚 → 魔 → 翔` 记录。

## 协作量谱

- 兽心技包含翔、猛、坚、魔四种属性。
- 发动兽心技时，协作量谱会点亮对应属性。
- 驯兽师或魔兽一方发动兽心技后，另一方在 7 秒内发动技能，可以触发兽心协作技追击伤害。
- 协作次数越多，兽心协作技威力越高。
- 按属性循环触发协作技，可以进入更强的生息或死灭协作技状态。

## 高级技能开关

自动输出页面和自动输出悬浮窗均提供以下开关：

- 高级技能总开关
- 御兽协作（黄豆）
- 兽灵协作（蓝豆）

默认关闭。两个协作模式互斥；关闭高级技能总开关时只保留技力和兽力，不会因为资源达到门槛而自动使用协作技或大招。开启后，程序会按所选模式显示候选技能和资源判断。

悬浮窗的“高级技能候选”分区会显示当前魔兽属性、大招名称、协作候选以及各自的开关和不可用原因。大招和魔兽“释放”技能都使用 `ActionType.Action` 对当前目标请求；释放技能以基础 ID `44890` 通过 `GetAdjustedActionId` 获取运行时实际 ID（例如截图中的 `47092`），参考 DLL 将它包装为目标型 `PAction` 入队。

## 待核对项

- `+0x10` 在反编译代码中命名为 `Tp`，当前插件显示名称为“技力”，上限为 250。
- `+0x11` 在反编译代码中命名为 `BeastPower`，当前插件显示名称为“兽力”，上限为 250。
- 目前属性映射已经通过客户端 Action 表全部核对；如果客户端版本更新，需要重新执行 DEBUG 按钮确认 IconId 是否变化。
