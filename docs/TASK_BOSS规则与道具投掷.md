# BOSS 规则与奇弈道具验证记录

## 状态

基础规则与牙投掷已随 `0.1.26.0` 发布并验证；后续新增的组合条件、血量条件和扩展奇弈道具仍需持续游戏内验证。

## 已验证

- `TargetStatus` 的 BUFF 存在和缺失条件能够正确匹配并执行技能。
- `DataIdStatus` 的 BUFF 存在和缺失条件能够正确查找场景对象并执行技能。
- `TargetDataId` 能够按当前目标 `BaseId` 匹配规则。
- 奇弈道具规则选择“恢复类道具”时按套装 `140` → 4/3/2/1级恢复药 `79/78/77/76` → 3/2/1级药粉 `82/81/80` → 吸血药 `135` → 吸血鬼之牙 `134` 选择；仅吸血鬼之牙要求当前目标。
- 奇弈道具规则选择“各种牙”时能对当前目标使用可用的牙。
- 已收录火 `128`、冰 `129`、水 `130`、雷 `131`、土 `132`、风 `133` 六种元素牙。
- 规则奇弈道具支持吸血鬼之牙 `134`（当前目标）、反射之书 `136`、闪躲之书 `137`、时之沙 `138` 和魔兽刚力药 `104`（自身目标）。
- 奇弈道具通过 Agent 497 显示槽位映射、InstanceContentDirector 库存校验和 `RaptureHotbarModule.ExecuteSlot` 执行。
- 目标道具使用时将 SoftTarget 临时设置为当前目标；恢复药使用时设置为玩家自身，执行后恢复原 SoftTarget。
- 奇弈道具 DEBUG 列表按 ID 去重并过滤 `76~143` 之外的伪条目。
- 规则完整诊断能够输出成功动作；相同失败原因不会重复刷屏，原因变化或成功恢复后重新输出。
- 单条规则最多支持 10 个检测条件，可选择全部满足（AND）或任意满足（OR）；命中规则执行失败时继续检查后续规则，全部不可执行后才回退 ACR。
- 规则支持自身/目标血量、大于/小于阈值和 IsBoss（目标最大 HP 严格大于自身最大 HP 5 倍）检测。

## 默认规则

默认规则集仅在 TerritoryType `1339~1343` 生效，并包含默认开启的规则：

```text
[规则]
名称|最终爆发-1层
启用|True
检测|TargetDataId
执行|CrucibleItem
奇弈道具类型|Fang
DataId|19344
```

## 当前范围

- 不实现“只提示 / 手动释放 / 自动释放”三种模式；规则命中后直接尝试执行，失败则继续后续规则。
- 目标 DATAID、目标血量和 IsBoss 可通过 AND/OR 条件组合实现最终爆发规则。
- 自动输出释放另提供三笛独立目标血量阈值与“只打BOSS”开关，不依赖规则模式。
