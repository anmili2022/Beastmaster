# BOSS 规则与奇弈道具验证记录

## 状态

任务已完成并在游戏内验证，随 `0.1.26.0` 发布。

## 已验证

- `TargetStatus` 的 BUFF 存在和缺失条件能够正确匹配并执行技能。
- `DataIdStatus` 的 BUFF 存在和缺失条件能够正确查找场景对象并执行技能。
- `TargetDataId` 能够按当前目标 `BaseId` 匹配规则。
- 奇弈道具规则选择“恢复药”时按 3级 `78` → 2级 `77` → 1级 `76` 对自身使用。
- 奇弈道具规则选择“各种牙”时能对当前目标使用可用的牙。
- 已确认火之牙 `128`、冰之牙 `129`、雷之牙 `131`、风之牙 `133`。
- 奇弈道具通过 Agent 497 显示槽位映射、InstanceContentDirector 库存校验和 `RaptureHotbarModule.ExecuteSlot` 执行。
- 目标道具使用时将 SoftTarget 临时设置为当前目标；恢复药使用时设置为玩家自身，执行后恢复原 SoftTarget。
- 奇弈道具 DEBUG 列表按 ID 去重并过滤 `76~143` 之外的伪条目。
- 规则完整诊断能够输出成功动作；相同失败原因不会重复刷屏，原因变化或成功恢复后重新输出。

## 默认规则

默认规则集仅在 TerritoryType `1339~1343` 生效，并包含默认开启的规则：

```text
[规则]
名称|最终爆发-1层
启用|True
检测|TargetDataId
执行|CrucibleItem
奇弈道具类型|Fang
DataId|19344
```

## 范围决定

以下功能已取消，不再实现：

- “只提示 / 手动释放 / 自动释放”三种模式。
- 独立的“目标血量低于阈值 + 指定笛号”最终爆发功能。

现有“最终爆发-1层”是目标 DATAID 匹配后使用各种牙的默认规则，与已取消的血量阈值和笛号功能无关。
