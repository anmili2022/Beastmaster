# 驯兽 ACR 设计说明

## 目标

驯兽 ACR（`驯兽ACR`）负责在玩家明确开启自动输出后，围绕当前手动选择的目标执行基础连击和捕获流程，并为高级技能提供可控的资源判断与开关。

设计原则：

- 默认不自动输出。
- 默认不自动使用高级技能。
- 只对玩家当前手动选择的目标执行动作。
- 捕获状态必须校验 `StatusId` 和 `SourceId`。
- 量谱和运行时状态读取只读，不写入游戏内存。
- 任何关键状态无法确认时，停止高级技能动作并显示原因。
- 推荐组合仅作为静态攻略展示，不接入自动输出决策、自动切笛或自动切换魔兽。

## 推荐组合

插件主窗口提供独立的“推荐组合”栏目，当前只展示静态攻略内容。

### 虫队：1、2 层速刷

推荐阵容：螳螂、胡蜂、库西。

1 笛召唤螳螂，施加物理易伤并使用释放技能，再使用最后一击；2 笛召唤胡蜂，使用释放技能进行自爆；3 笛召唤库西，使用释放技能后正常输出。整个流程的主要难点是螳螂的物理易伤不能空放。

### 水队：参考阵容

推荐阵容：蝾螈、巨型陆蟹、壳蟹。

蝾螈和巨型陆蟹分别负责魔法易伤与水属性易伤，壳蟹作为三号位主力输出。开战前先切换三号兽笛准备壳蟹的借用。1 笛召唤蝾螈，施加魔法易伤（释放），再使用最后一击；2 笛召唤巨型陆蟹，施加水属性易伤（释放），打一套连携之后使用最后一击；3 笛召唤壳蟹，正常输出。这里的“释放”指魔兽的释放技能。借用的水栖波用于远程止损，尽量安排在易伤 Buff 期间，也可以用于驱散敌方增益 Buff。

### 水队：1、2 层速刷变体

推荐阵容：蝾螈、巨型陆蟹、碧企鹅。

三号位使用高魔法伤害的碧企鹅。开战前先切换三号兽笛准备碧企鹅的借用。1 笛召唤蝾螈，施加魔法易伤（释放），再使用最后一击；2 笛召唤巨型陆蟹，施加水属性易伤（释放），无需等待完整连携，直接使用最后一击；3 笛召唤碧企鹅，正常输出。这里的“释放”指魔兽的释放技能。

参考视频：夜风，Bilibili 视频 BV1c1Y46AEnN，链接由推荐组合页面按钮打开。

投稿来源：网友“大三元”。

## 当前已实现

### 斗兽塔导航

工具列表提供“前往斗兽塔”栏目，点击“开始导航”后复用现有飞行导航和跨区传送流程，目标为 `TerritoryType=148`、`Map.RowId=4`、黑衣森林中央林区世界坐标 `X=24.238, Y=-6.003, Z=65.809`。

自动输出栏目提供默认关闭的“悬浮窗三列模式”开关。开启后悬浮窗高级技能按钮按三列排列：第一行御兽协作、兽灵协作、鼓劲；第二行万象·物理、万象·魔法、声援；第三行自动兽笛、最后一击、释放；第四行持续吸引、持续挑衅、待定。关闭时使用双列布局。

### 主动攻击

自动输出提供独立的“主动攻击”开关，悬浮窗标题栏显示可点击的“主动”标签：绿色表示开启，灰色表示关闭。

主动攻击关闭且玩家尚未进入战斗时，普通 ACR 不使用捕获、基础连击或高级目标技能；进入战斗后恢复正常决策。自动兽笛等无目标战前准备动作仍可运行。技能序列不受主动攻击开关限制；规则模式只在战斗中运行。两者仍要求自动输出总开关开启且未暂停。

旧配置升级时主动攻击默认开启，以保留既有行为；新配置默认关闭，避免选中目标后意外开怪。

### 基础自动输出

基础技能顺序：

```text
碎击斩 → 碎咬斧 → 裂盾劈
```

基础自动输出使用客户端稳定 RowId 判断和请求动作，不通过本地化技能名称解析：

| 用途 | RowId |
| --- | ---: |
| 碎击斩 | `44879` |
| 碎咬斧 | `44883` |
| 裂盾劈 | `44885` |
| 捕获 | `44880` |
| 捕获状态 | `4626` |

技能名称仅用于 UI 显示。客户端语言切换到国际服英文等环境时，不应依赖中文 Action 或 Status 名称作为运行时键。

执行前检查：

- 自动输出已开启。
- 玩家为驯兽师。
- 玩家存在、存活且没有读条。
- 不在切图、骑乘或剧情占用状态。
- 角色 HP 从 `0` 恢复为大于 `0` 后进入 3 秒复活保护，期间技能序列、规则模式、自动兽笛和普通 ACR 均不执行任何动作。
- 当前目标是可选中的 BattleNpc。
- 目标存在、存活且 HP 大于 0。
- `ActionManager` 可用且允许使用目标技能。

### 捕获流程

捕获标签有三种状态，悬浮窗标题栏点击标签按以下顺序循环：

```text
灰色“捕获”（尝试捕获和强制捕获均关闭）
→ 绿色“捕获”（尝试捕获开启）
→ 红色“捕获”（强制捕获开启）
→ 灰色“捕获”
```

绿色捕获状态下：

```text
目标血量 <= 捕获阈值
且目标没有自身施加的捕获状态
→ 选择捕获
```

目标血量高于阈值时继续基础连击。捕获阈值范围为 `1%~100%`，默认 `80%`，可在主页面和悬浮窗修改。

基础连击碎击斩 `44879`、碎咬斧 `44883`、裂盾劈 `44885` 的玩家到目标距离门禁统一按 `6 yalms` 判断；距离使用施法者中心到目标碰撞箱边缘，避免大型目标或中心距离约 `6.06` 时误判超距。超过该距离时不向动作系统发送请求，避免角色反复转向目标。其他玩家目标技能优先使用 `ActionManager.GetActionRange`，无法取得时回退 Action 表 `Range`；召唤兽释放距离同样扣除目标碰撞半径。

红色捕获状态为强制捕获：忽略目标已有捕获 Buff，但仍受目标血量阈值限制；同时受捕获请求后的等待窗口保护，不会在结果确认前重复请求。自动输出栏目提供“强制捕获”复选框；开启该选项会同步开启尝试捕获，关闭尝试捕获会同步关闭强制捕获。

捕获状态来源：

```text
status.StatusId == 捕获状态
且 status.SourceId == LocalPlayer.EntityId
→ 自身捕获状态
```

他人施加的同名状态不会阻止自身捕获判断。

捕获请求发送后进入短暂等待窗口，等待自身 `SourceId` 状态刷新；等待期间不会重复请求捕获，也不会继续对目标造成伤害。目标切换、目标失效或自动输出关闭时重置捕获状态。

“角色状态”拦截原因会拆分显示为技能节流等待、正在切图或传送、当前处于骑乘状态、剧情或特殊事件占用、角色已死亡、角色正在读条，避免国际服反馈时只能看到笼统的不可执行原因。

从以下地址只读采样 48 字节：

```text
JobGaugeManager.Instance()->CurrentGauge
```

字段：

| 字段 | 偏移 | 上限/拆分 |
| --- | --- | --- |
| 技力 | `+0x10` | `250` |
| 兽力 | `+0x11` | `250` |
| 当前兽笛 | `+0x13` | `1~3` 为对应兽笛 |
| 御兽之心 | `+0x18` | `raw >> 2` |
| 兽灵之心 | `+0x18` | `raw & 3` |

采样周期为 100ms，UI 使用缓存快照。

## 魔兽资料模型

图鉴编号与召唤物 DataId 的关系：

```text
DataId = 18915 + 图鉴编号
```

每个图鉴条目提供统一技能资料：

```text
BeastmasterSkillProfile
├── 图鉴编号
├── 魔兽名称
├── SummonDataId
├── 属性：猛 / 坚 / 魔 / 翔
├── 大招 ActionId
└── 释放 ActionId
```

注意：图鉴中的“大招 ActionId”是当前魔兽对应的宠物技能资料，用于识别属性；玩家实际释放驯兽师职业大招使用固定的 ActionId `47093`。

属性由大招 IconId 映射：

```text
3906 → 猛
3907 → 坚
3908 → 魔
3909 → 翔
```

## 高级技能开关

悬浮窗和主窗口都提供：

```text
御兽协作（黄豆）
兽灵协作（蓝豆）
万象流转（物理）
万象流转（魔法）
自动兽笛
自动最后一击
释放
```

开关关系：

```text
御兽协作（黄豆）和兽灵协作（蓝豆）互斥
→ 同时开启时自动关闭另一项

万象流转（物理）和万象流转（魔法）互斥
→ 同时开启时自动关闭另一项

释放关闭时，不自动请求当前召唤兽的 `ReleaseActionId`；手动协作流程仍由对应的黄豆/蓝豆选项控制。
```

高级技能支持以下调用路径：

- 手动大招按钮：通过悬浮窗主动请求固定职业大招 `47093`。
- 自动协作：在对应协作模式、当前魔兽和资源条件均满足时，按模式接入自动技能选择；大招由协作流程自动包含。
- 魔兽释放技能：“释放”开关开启后，以基础 ActionId `44890` 调用 `GetAdjustedActionId` 获取请求用 ActionId；射程从当前召唤兽图鉴条目的 `ReleaseActionId` 对应 Action 行读取，优先使用 `Range`，为 `0` 时使用 `EffectRange`。以召唤兽位置到目标碰撞箱边缘计算距离；存在有效射程且召唤兽未进入距离时不调用 `UseAction`，`Range` 与 `EffectRange` 均为 `0` 时跳过显式距离门禁并交给 `GetActionStatus` 判断。普通 ACR、规则模式和技能序列中的玩家目标技能也会检查玩家到目标的距离。释放与御兽之心/黄豆不是同一套状态，不能用黄豆变化确认释放完成。
- “自动输出诊断”采用单一总开关，不提供模块筛选或发呆报警。开启后由插件内部记录全部普通 ACR 模块的状态边沿、技能成功请求和失败原因，不持续向聊天框输出汇总。相同技能和原因类别不会因轮询、距离数值或资源数值变化重复记录；可用性、状态码类别或技能发生变化时记录新边沿。
- 自动输出诊断折叠栏提供战斗日志下拉选择、复制和清空。进入战斗时开始记录，离开战斗时归档；内存中保留最近 10 场，每场最多 500 条，插件重载后清空。日志用于事后分析发呆原因，不读取聊天框。
- 兽笛循环连招已保留实现但当前暂时禁用，未接入自动决策入口。恢复时的设计顺序为：一号兽笛（`44881`，要求未进入战斗）→ 释放（基础 `44890`，运行时调整）→ 最后一击（`44891`）→ 二号兽笛（`44892`）→ 释放 → 最后一击 → 三号兽笛（`44894`）→ 释放。
 - 该循环完成后自动关闭，并等待一号兽笛冷却完成后才允许再次启动；关闭开关或自动输出时应清空阶段和冷却等待状态。

三式提供“物理”和“魔法”两个互斥模式。任一模式开启后，只有玩家自身状态列表已经存在生息或死灭状态，并且御兽之心达到 3 层时，才使用无目标技能鼓劲 `44905`；缺少任一条件都不会释放鼓劲。黑白状态不校验 `SourceId`，与参考 DLL 的 `HasStatus` 判断一致。鼓劲消耗黄豆后，按客户端实测映射选择终结技能；该映射与参考 DLL 的反编译结果相反：

| 状态 | 万象流转（物理） | 万象流转（魔法） |
| --- | --- | --- |
| 生息（白，`4599`） | 利鹰坚爪 `44931` | 灾祸天翔 `44933` |
| 死灭（黑/紫，`4600`） | 狂猛怒火 `44930` | 升魔暴落 `44932` |

鼓劲优先于三式终结技能；所有三式动作仅在 `GetActionStatus == 0` 时请求。三式第二段需要有效的当前敌对目标。

自动兽笛开启后，只在当前没有召唤魔兽时运行。程序按一号 `44881`、二号 `44892`、三号 `44894` 的顺序检查，并使用第一个 `GetActionStatus == 0` 的兽笛。请求成功后进入 1 秒召唤确认窗口，每 100ms 检查当前兽笛量谱或己方召唤物；确认窗口结束前不会检查或使用下一支兽笛，避免客户端召唤延迟导致连续使用兽笛 1 和兽笛 2。关闭自动兽笛、暂停或关闭自动输出时清理等待状态。

鼓劲 `44905` 和声援 `44904` 为独立高级技能开关，默认关闭；鼓劲在御兽之心为 `0` 时正常判断，御兽之心大于 `0` 时仅在开启任一万象流转开关后继续判断；声援使用相同规则对应兽灵之心：兽灵之心为 `0` 时正常判断，大于 `0` 时要求开启任一万象流转开关。两者均为无目标技能，状态不可用或请求失败时回退其他输出。

悬浮窗高级技能使用按钮开关。双列模式依次为协作、万象流转、鼓劲/声援、自动兽笛/待定、释放/最后一击、持续吸引/持续挑衅；三列模式按四行三列排列。持续吸引与持续挑衅按钮直接切换规则模式内对应的内置斗兽塔规则，开启时使用淡黄色背景；规则绑定使用 ActionId 与状态 ID，不依赖可编辑名称。
自动输出栏目显示普通 ACR 技能优先级：协作二段 → 释放 → 最后一击 → 鼓劲 → 声援 → 万象流转 → 协作一段 → 捕获 → 基础技能；技能序列和规则模式按各自接管优先级先行处理。悬浮窗不显示该说明。

最后一击按当前 `1/2/3` 号兽笛分别提供独立开关和 `1%~100%` 的宝宝血量阈值，默认 `20%`。插件从己方召唤物读取当前/最大 HP；当最后一击总开关开启、当前兽笛对应开关开启、宝宝仍存活且血量小于等于该笛阈值、当前敌对目标有效，并且最后一击 `44891` 的 `GetActionStatus == 0` 时，对当前敌对目标请求该技能；`100%` 阈值包含满血宝宝。技能不可用时回退其他输出，不阻塞基础连击。悬浮窗只保留一个最后一击功能总开关，不修改三笛独立设置；各笛位开关和阈值仅在自动输出栏目的高级技能中设置。

“最后一击 · 等待释放”开启后，只有当前召唤兽的调整后释放技能不可用时，才允许使用最后一击。释放技能状态可用但召唤兽尚未进入释放距离时，仍继续等待释放，不能绕过距离条件使用最后一击。该判断不依赖“释放”自动开关，释放可以由自动逻辑或手动操作完成；切换兽笛、召唤兽变化或消失时重新判断当前释放状态。

基础技能（1→2→3）有独立开关。关闭后仍保留捕获和已启用的高级技能，但不会自动使用碎击斩、碎咬斧和裂盾劈。

规则模式内置“斗兽塔技能”规则集，仅在 TerritoryType `1339~1343` 生效，两条规则默认关闭：

- 持续吸引（宝宝抗）：自身状态列表没有被保护 `2413` 时，使用无目标技能吸引注意 `46751`。
- 持续挑衅（自己抗）：自身状态列表没有仇恨上升 `5586` 时，使用无目标技能挑衅 `46750`。

两项同时开启时按规则顺序优先补持续吸引。技能状态非零或请求失败时发送节流诊断并回退其他输出，不阻塞技能序列、自动兽笛、捕获或基础连击。区域不在 `1339~1343` 时不执行这两项规则。

区域范围使用 `ClientState.TerritoryType` 判断，包含首尾 `1339`、`1340`、`1341`、`1342`、`1343`。DEBUG 关键词查询提供“区域”类型：输入数字时按 `TerritoryType.RowId` 精确查询，输入文字时按区域名称模糊查询，并输出区域名、`Map.RowId` 和关联的 `ContentFinderCondition`。

悬浮窗标题栏的“自动/暂停”按钮可随时暂停或恢复自动输出；暂停是独立状态，不会关闭自动输出总开关。自动输出栏目也提供相同的暂停开关。暂停会清理捕获等待和协作待续状态，避免恢复后继续旧流程。

大招调用会保留目标、职业、量谱、射程和 `ActionManager` 检查。所有普通 ACR 技能仅在 `GetActionStatus == 0` 时调用 `UseAction`，不再使用状态码非零时的请求兜底。

协作技按两段候选流程请求。第一段成功后保存第二段及预期的一式属性状态，并在 7 秒窗口内等待人物自身状态列表出现对应 Buff：翔 `4595`、猛 `4596`、坚 `4597`、魔 `4598`。检查不校验 `SourceId`；等待 Buff 期间保留第二段最高优先级，但允许普通 ACR 回退执行释放、捕获和基础连击，避免等待窗口造成发呆。Buff 出现后下一轮立即优先执行第二段。

- 御兽协作（黄豆）：大招作为第一段；召唤兽前摇可能延迟大招结算，出现当前魔兽属性对应的一式 Buff 后，才释放技力技第二段以获得黄豆。
- 兽灵协作（蓝豆）：属性技作为第一段；出现该属性技对应的一式 Buff 后，才释放大招第二段以获得蓝豆。

目标切换、暂停、关闭自动输出或等待超时会清除待续状态。

## 国际服兼容规则

- 自动输出、导航和图鉴排序优先使用稳定 ID：`Action.RowId`、`Status.RowId`、`TerritoryType.RowId`、`Map.RowId`、`ContentFinderCondition.RowId`。
- 中文名称保留为界面文案、资料展示和缺少稳定 ID 时的最后回退，不作为自动输出动作选择的唯一依据。
- 野外图鉴导航优先按 `Map.RowId + TerritoryType` 定位地图，其次按 `TerritoryType`，最后才按本地化地图名回退。
- DEBUG 的“自动输出状态”用于回传 `BetweenAreas`、`Mounted`、`OccupiedInCutSceneEvent`、`InCombat`、HP、读条和目标状态。
- 图鉴同步读取 `XBMMonsterNotebook` 的原生 `AtkValue`。编号数值、捕获 Bool 和图标 RowId 参与结构校验；`1`、`No.1` 等编号显示文本只用于诊断，不参与校验，避免客户端语言差异导致同步失败。
- 图鉴同步仍要求两页共 50 项、页码有效、两页捕获总数一致，并核对捕获 Bool 与图标 RowId；任一语言无关字段异常时停止同步，不覆盖角色原有进度。
- 图鉴同步失败时保留诊断文本，可通过“复制同步诊断”取得页码、`AtkValuesCount` 以及编号、捕获、图标和文本字段的原始类型和值，便于核对客户端版本差异。

## 技能序列设计

技能序列要求自动输出总开关已开启且未暂停，只由游戏原生团队倒计时触发；战斗阶段仅接续同一次倒计时，不独立启动。序列运行时临时取得 ACR 决策优先权，完成或中止后恢复普通 ACR，并且不受“主动攻击”开关限制。

已确认的稳定 Action RowId：

| 技能 | RowId |
| --- | ---: |
| 碎击斩 | `44879` |
| 一号兽笛 | `44881` |
| 魔兽技 | `44886` |
| 释放 | `44890` |
| 最后一击 | `44891` |
| 二号兽笛 | `44892` |
| 盾牌冲击 | `44893` |
| 三号兽笛 | `44894` |
| 借用 | `44895` |
| 百兽肤 | `44896` |
| 百虫肤 | `44897` |
| 有翼飞掠 | `44898` |
| 草木播种 | `44899` |
| 水栖波 | `44900` |
| 甲鳞肤 | `44901` |
| 咒具碎魂 | `44902` |
| 死尸净化 | `44903` |
| 鼓劲 | `44905` |

`魔兽技 44886` 和 `释放 44890` 必须通过 `GetAdjustedActionId` 取得当前实际技能。借用成功后，从当前序列后续倒计时步骤中读取预期本能技能（`44896~44903`），并等待 `GetAdjustedActionId(44886)` 与其一致；例如虫队模板要求调整为百兽肤 `44896`。到该技能计划执行时间仍未匹配时中止序列，避免误用其他本能技能。

客户端实测：三号笛为库西时，`借用 44895` 调整为 `47238`，`魔兽技 44886` 调整为 `百兽肤 44896`，`释放 44890` 调整为 `47092`。序列应请求调整后 ID，不直接写死这些运行时结果。

倒计时读取参考 AE3：从 `AgentId.CountDownSettingDialog` 对应 Agent 读取 `Timer @ 0x28`、`Active @ 0x38`、`Initiator @ 0x3C`。当前阶段只提供只读快照与 DEBUG 验证，不安装签名 Hook；读取会检查空指针、非有限数值以及 `0~3600` 秒范围。

倒计时由独立缓存服务轮询。自动输出关闭、暂停、未登录或职业不是驯兽师时不访问 Agent；满足前置条件后，待机状态每 `100ms` 采样一次，倒计时激活后每 `50ms` 采样一次。DEBUG 和后续技能序列执行器只读取缓存，不在 UI 绘制帧中直接访问 Agent。

实测取消倒计时后 `Active=False`、`Timer=0`、`Initiator=0`。缓存服务记录倒计时边沿：非激活到激活为开始；激活到非激活且上一采样剩余时间大于 `0.25s` 为取消；上一采样已接近零则为自然归零。最近边沿和时间保留在 DEBUG 中，避免必须在变化瞬间读取。

DEBUG“技能序列验证数据”输出原生倒计时状态、当前兽笛和召唤兽、目标、战斗状态，以及借用、魔兽技、释放、本能技能和盾牌冲击的基础/调整后 ActionId 与状态码。

技能序列栏目提供默认关闭的“序列诊断”开关。开启后仅在序列启动、技能请求成功、进入战斗、完成和中止时输出本地聊天信息；前缀格式为 `[驯兽师序列诊断 HH:mm:ss]`，失败重试轮询不输出，相同消息在 2 秒内去重。

当前提供可恢复的内置“虫队模版序列”，启用后仅从下一次团队倒计时开始执行，不追加入场中已经开始的倒计时：

```text
T-9  三号兽笛
T-5  借用
T-4  一号兽笛
T-2  魔兽技（必须调整为百兽肤）
T-0  盾牌冲击
进入战斗后：
碎击斩 → 鼓劲 → 释放
碎咬斧 → 声援 → 最后一击
裂盾劈 → 二号兽笛 → 释放
三号兽笛
```

序列运行时优先于规则模式、自动兽笛和普通 ACR。每一步按实际调整后的 ActionId 读取 `ClassJobLevel`，角色等级不足时直接跳过并继续序列，包括关键倒计时技能。序列中的释放步骤与普通 ACR 共用召唤兽到目标的距离门禁。倒计时取消、步骤超时、目标失效、切图、切换职业、角色死亡、自动输出关闭或暂停时中止；完成或中止后归还普通 ACR 控制。每个战斗步骤超时为 8 秒，盾牌冲击后等待进入战斗的窗口为 2 秒。

同时内置默认关闭的“测试序列”，流程为 `T-3 一号兽笛 → T-0 盾牌冲击 → 进入战斗后碎击斩`，用于验证倒计时、兽笛确认、目标技能和战斗阶段接续。

## 规则模式

规则模式是独立的规则配置栏目，采用“规则集 → 有序规则”结构。“规则诊断”全局开关位于“启用规则模式”下方并默认关闭；开启后再按各规则集的规则诊断级别决定输出失败或完整信息。规则集支持启用开关、`TerritoryType` 区域包含/排除；规则支持自身 BUFF、目标 BUFF、DataID BUFF、DataID 读条和目标读条检测。BUFF 条件可选择存在或缺失，技能使用稳定 `Action.RowId`。

规则模式仅在 `ConditionFlag.InCombat` 为真时检查和执行。规则集和规则均按界面顺序检查，越靠前优先级越高。DataID 检测遍历当前场景内存活的战斗 NPC，但规则技能始终对当前手动目标释放，不会自动切换目标。规则命中后技能不可用或请求失败时，按规则集诊断设置发送节流默语，并回退给普通 ACR。

规则集可使用带 `BSTRULESET|1` 版本头的文本导入导出；导入会新增规则集，不覆盖已有配置。每个规则集最多 100 条规则、100 个区域 ID。规则模式默认开启，内置斗兽塔规则集包含默认关闭的持续吸引与持续挑衅，配置版本为 19。

## 技能决策优先级

当前决策顺序：

```text
自动输出总开关与暂停状态
→ 角色状态
→ 技能序列
→ 战斗中的规则模式
→ 规则集区域限制内的规则
→ 当前目标
→ 捕获等待保护
→ 待续协作第二段
→ 无魔兽时自动兽笛
→ 宝宝低血量时自动最后一击
→ 三式（黑白状态 + 3 层御兽之心）
→ 魔兽释放技能
→ 协作技第一段
→ 捕获判断或基础 1-2-3 连击
```

高级技能处于冷却、未开启或关键数据缺失时回退到捕获判断或基础连击，不阻塞 1-2-3。暂停时不执行任何动作，并清理捕获等待和协作待续状态。

## 上线验证清单

验证时优先使用 DEBUG 页的“读取协力验证数据”按钮。该按钮只读输出量谱、当前魔兽、目标、关键 Action 状态码和自身属性状态。

### 验证步骤

1. 进入安全区域，切换驯兽师，不开自动输出，召唤任意魔兽。
2. 点击“读取协力验证数据”，记录初始技力、兽力、心数、兽笛、魔兽属性和自身属性状态。
3. 只使用普通技能，等待量谱变化，再点击一次按钮，确认 `+0x10` 和 `+0x11` 的变化方向。
4. 开启自动输出，但先关闭两个协力模式，确认基础连击不受影响。
5. 开启“御兽协作（黄豆）”，在技力、兽力达到要求后记录悬浮窗下一技能；确认是否先请求 `47093`。
6. 第一段技能完成后立即点击“读取协力验证数据”，记录自身属性状态、Action 状态码和量谱变化。
7. 在 7 秒内再次点击按钮，确认第二段属性斧所需状态和实际 Action 状态码。
8. 关闭黄豆，开启“兽灵协作（蓝豆）”，重复步骤 5~7，确认第一段是否为属性斧、第二段是否为 `47093`。
9. 分别测试两种模式同时开启，确认 UI 自动关闭其中一个，不能同时运行。
10. 测试切换目标、目标死亡、召唤兽消失和切换职业，确认待续段会被清除且不会对旧目标继续请求技能。

每个阶段至少回传：

- 悬浮窗截图或文字：下一技能、原因、捕获状态。
- “读取协力验证数据”的完整输出。
- 实际是否释放了第一段和第二段。
- 两段技能之间的时间间隔。

- 对照原生量谱确认技力和兽力变化。
- 确认大招实际资源消耗和 ActionManager 状态。
- 确认当前兽笛字段在召唤、切换和消失时的值。
- 采集协作量谱状态和 7 秒协作窗口。
- 确认生息/死灭中心状态字段。
- 验证自身捕获与他人捕获状态的 SourceId。
- 验证目标切换、捕获失败、目标死亡和召唤兽消失。

## 安全边界

以下任一条件不满足时，不得自动释放高级技能：

- 量谱读取失败。
- 当前魔兽未知。
- 属性未知。
- ActionId 无效。
- 目标无效。
- 资源门槛未知。
- 协作窗口未知。
- ActionManager 拒绝使用。
