# 驯兽 ACR 设计说明

## 目标

驯兽 ACR（`驯兽ACR`）负责在玩家明确开启自动输出后，围绕当前手动选择的目标执行基础连击和捕获流程，并为高级技能提供可控的资源判断与开关。

设计原则：

- 默认不自动输出。
- 默认不自动使用高级技能。
- 只对玩家当前手动选择的目标执行动作。
- 捕获状态必须校验 `StatusId` 和 `SourceId`。
- 量谱和运行时状态读取只读，不写入游戏内存。
- 任何关键状态无法确认时，停止高级技能动作并显示原因。

## 当前已实现

### 基础自动输出

基础技能顺序：

```text
碎击斩 → 碎咬斧 → 裂盾劈
```

执行前检查：

- 自动输出已开启。
- 玩家为驯兽师。
- 玩家存在、存活且没有读条。
- 不在切图、骑乘或剧情占用状态。
- 当前目标是可选中的 BattleNpc。
- 目标存在、存活且 HP 大于 0。
- `ActionManager` 可用且允许使用目标技能。

### 捕获流程

捕获开关开启时：

```text
目标血量 < 捕获阈值
且目标没有自身施加的捕获状态
→ 选择捕获
```

目标血量高于阈值时继续基础连击。捕获阈值范围为 `1%~100%`，默认 `80%`，可在主页面和悬浮窗修改。

捕获状态来源：

```text
status.StatusId == 捕获状态
且 status.SourceId == LocalPlayer.EntityId
→ 自身捕获状态
```

他人施加的同名状态不会阻止自身捕获判断。

捕获请求发送后进入短暂等待窗口，等待自身 `SourceId` 状态刷新；等待期间不会重复请求捕获，也不会继续对目标造成伤害。目标切换、目标失效或自动输出关闭时重置捕获状态。

### 量谱读取

从以下地址只读采样 48 字节：

```text
JobGaugeManager.Instance()->CurrentGauge
```

字段：

| 字段 | 偏移 | 上限/拆分 |
| --- | --- | --- |
| 技力 | `+0x10` | `250` |
| 兽力 | `+0x11` | `250` |
| 当前兽笛 | `+0x13` | `1~3` 为对应兽笛 |
| 御兽之心 | `+0x18` | `raw >> 2` |
| 兽灵之心 | `+0x18` | `raw & 3` |

采样周期为 100ms，UI 使用缓存快照。

## 魔兽资料模型

图鉴编号与召唤物 DataId 的关系：

```text
DataId = 18915 + 图鉴编号
```

每个图鉴条目提供统一技能资料：

```text
BeastmasterSkillProfile
├── 图鉴编号
├── 魔兽名称
├── SummonDataId
├── 属性：猛 / 坚 / 魔 / 翔
├── 大招 ActionId
└── 释放 ActionId
```

注意：图鉴中的“大招 ActionId”是当前魔兽对应的宠物技能资料，用于识别属性；玩家实际释放驯兽师职业大招使用固定的 ActionId `47093`。

属性由大招 IconId 映射：

```text
3906 → 猛
3907 → 坚
3908 → 魔
3909 → 翔
```

## 高级技能开关

悬浮窗和主窗口都提供：

```text
高级技能
自动大招
自动协作技
```

开关关系：

```text
高级技能关闭
→ 所有高级技能保留资源

高级技能开启 + 自动大招关闭
→ 不使用大招

高级技能开启 + 自动协作技关闭
→ 不使用协作技
```

高级技能支持两种调用路径：

- 手动大招按钮：通过悬浮窗主动请求固定职业大招 `47093`。
- 自动大招：在高级技能总开关、自动大招开关、当前魔兽和资源条件均满足时，接入自动技能选择。

大招调用会保留目标、职业、量谱和 `ActionManager` 检查。`GetActionStatus` 返回非零时仍尝试一次 `UseAction`，由动作系统决定是否接受；基础连击和捕获不使用该兜底。

协作技目前仍只生成候选和判断提示，不调用协作技 `UseAction`，因为 7 秒协作窗口和运行时量谱状态尚未确认。

## 技能决策优先级

计划中的决策顺序：

```text
角色状态
→ 当前目标
→ 捕获判断
→ 基础连击
→ 魔兽/属性识别
→ 技力和兽力判断
→ 高级技能开关
→ ActionManager 可用性
→ 高级技能释放
```

当高级技能未开启或关键数据缺失时，回退到基础连击，不影响捕获安全判断。

## 安全边界

以下任一条件不满足时，不得自动释放高级技能：

- 量谱读取失败。
- 当前魔兽未知。
- 属性未知。
- ActionId 无效。
- 目标无效。
- 资源门槛未知。
- 协作窗口未知。
- ActionManager 拒绝使用。
